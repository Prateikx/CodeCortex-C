# Memory Management

Learn stack vs heap, dynamic allocation, ownership, lifetime, and common memory bugs.

## Exercises

1. Allocate an integer array with `malloc` and initialize it.
2. Resize it with `realloc` while checking for failure safely.
3. Free every allocation exactly once.
4. Deliberately identify examples of leaks, double-free, use-after-free, and dangling pointers.
5. Run your programs with AddressSanitizer and fix every reported error.

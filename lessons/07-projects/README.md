# Projects

Do not just collect syntax exercises. Build progressively harder programs.

## Project 1 — CLI Calculator

Operators, functions, input validation, and error handling.

## Project 2 — Contact Manager

Structs, dynamic memory, file I/O, search, update, and delete.

## Project 3 — Mini Shell

Processes, command parsing, pipes, and Unix system calls.

## Project 4 — Memory Allocator

Implement a simplified `malloc`/`free`-style allocator to understand heap management.

## Project 5 — HTTP Server

Sockets, request parsing, buffers, and concurrency basics.

# Pointers

This is where C starts becoming C rather than syntax practice.

## Exercises

1. Print the address of a variable using `%p`.
2. Write `swap(int *a, int *b)`.
3. Traverse an integer array using pointer arithmetic only.
4. Compare `arr[i]`, `*(arr + i)`, and a pointer variable.
5. Explain the difference between `int *p`, `int **p`, and `const int *p`.
